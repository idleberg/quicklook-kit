> Create Quick Look previews with Vite-based web frameworks

```sh
pnpm create quicklook my-preview
```

Asks for a template (SvelteKit, Astro, SolidStart, Nuxt, Analog or Alpine.js), the platforms to build for (macOS, Windows or both) and whether to add a GitHub release workflow. Skip the questions with `--template <name>`, `--platform macos` and/or `--platform windows`, and `--release` or `--no-release`.

The project uses [quicklook-kit](https://www.npmjs.com/package/quicklook-kit); see its readme for what to do next.
